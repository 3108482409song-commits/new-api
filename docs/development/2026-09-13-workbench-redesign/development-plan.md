# 工作台设计调整开发文档

> **修订记录（2026-09-14）**：「图片尺寸新增 `3:4` 与 `4:3`」这一条目**已被后续设计取代**。
>
> 实测上游能力：`gpt-image-1` / `1.5` / `mini` 只支持 `1024x1024`、`1536x1024`、`1024x1536`，**无法真实输出 3:4 / 4:3**；`dall-e-3` 的真实比例是 7:4 / 4:7，没有 16:9。若按原条目让所有模型都显示这三个比例，按钮标签必然与实际输出不一致。
>
> 实现改为**按模型真实支持的像素尺寸动态展示比例**：`gpt-image-1` 显示 `1:1 / 3:2 / 2:3`，`gpt-image-2` 显示全部七种，`dall-e-3` 显示 `1:1 / 7:4 / 4:7`，像素尺寸放在按钮 `title` 中便于核对。
>
> 因此下文「目标 1」「代码设计 · 图片尺寸」与「验收标准 · 功能」中涉及 `3:4` / `4:3` / `16:9` 的条目**均已取代**，以 [`../2026-09-13-workbench-image-connection/code-design.md`](../2026-09-13-workbench-image-connection/code-design.md) 的 §8.4 与 §9.4 为准（该文档另附第二轮、第三轮验收复审的完整处理记录）。
>
> 其余条目仍然有效：纵向区块布局、「计费分组」→「分组」的文案调整、分组切换重置模型、测试与 typecheck/lint 要求。

## 目标

本次变更只针对前端 Playground 的图片工作台：

1. ~~图片尺寸选项新增 `3:4` 与 `4:3`。~~ **（已被取代，见上方修订记录）**
2. 图片工作台左侧设置区参考提供的界面框架，使用“生成设置”标题、分组选择、模型选择等纵向区块；忽略示例中的具体分组和模型名称。
3. 将界面中的“计费分组”文案改为“分组”。

## 范围与约束

- 不调整后端接口、计费逻辑、模型路由或数据库结构。
- 复用现有 Workbench、分组/模型选择器、ToggleGroup、Label 等组件与样式体系。
- 图片比例仍映射为当前模型支持的像素尺寸，并保持不支持时的回退逻辑；映射依据由「固定候选表」改为**从模型真实支持的尺寸推导**。
- 所有新增用户可见文本走 i18n，英文 key 与其他 locale 保持同步。

## 代码设计

### 图片尺寸

> 本节原方案（固定优先级候选表）**已被取代**，实际实现见下。

- 原方案：在 `web/src/features/playground/lib/workbench-options.ts` 的 `IMAGE_ASPECT_OPTIONS` 增加 `3:4`（优先 `1024x1536`）与 `4:3`（优先 `1536x1024`）。
- **实际实现**：该写死列表已删除，改为由 `imageSizesForModel()` + `aspectRatioOf()` 按模型真实尺寸推导比例（`imageAspectOptions()`）；这样 `gpt-image-1` 不会出现无法产出的 `3:4` / `4:3`，`dall-e-3` 会如实标注 `7:4` / `4:7`。
- `ImagePanel` 继续使用同一组配置渲染选项、估价查询和提交参数，不新增重复状态或转换逻辑。

### 分组与模型设置区

- 复用现有 `GroupSelector` 与 `ModelSelector`，实现截图所示的纵向标签 + 选择器布局；共享选择器增加可选 `aria-label` 转发能力，保持原有调用兼容。
- 保持分组变化会清空并重新选择模型、模型列表按分组刷新、加载状态和禁用状态不变。
- 具体名称继续由后端返回，不在前端写死示例名称。

### 文案

- 图片工作台设置区显示“分组”，不再显示“计费分组”。
- 如共享组件被其他页面复用，优先通过可选 label/key 扩展保持旧调用兼容；仅在工作台调用点传入新的文案 key。

## 验收标准

### 功能

- 图片工作台尺寸选择器可见并**可选择该模型真实支持的**比例。~~`1:1`、`3:2`、`2:3`、`16:9`、`9:16`、`3:4`、`4:3` 全部可见~~ **（已被取代）**：`gpt-image-1` 为 `1:1 / 3:2 / 2:3`，`gpt-image-2` 为七种全量，`dall-e-3` 为 `1:1 / 7:4 / 4:7`。
- 选择任一比例后，估价请求和生成请求使用该比例对应的模型支持尺寸；按钮 `title` 显示实际像素尺寸（如 `3:4 · 1152x1536`）以便核对。
- 分组切换后模型列表刷新，当前模型重置为新分组可用模型。
- 设置区按“生成设置 → 分组 → 模型 → 其他图片参数”的纵向框架展示；移动端布局不回归。
- 页面显示“分组”，不显示“计费分组”。

### 质量与验证

- 更新图片设置相关测试，覆盖新增两个比例和选择器可访问名称。
- 执行受影响的 Vitest 测试；执行 `bun run typecheck` 与相关文件 lint。
- 不修改后端行为；若构建环境缺少 Bun 或依赖，需在交付说明中明确记录。
